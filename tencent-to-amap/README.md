# 腾讯地图 → 高德地图 (Tencent Map to Amap)

Tampermonkey / Violentmonkey 用户脚本，在腾讯地图网页版右下角注入直达按钮，一键在高德地图新版打开相同位置。

## 核心特性

- **优先选定地物 (POI)**：智能探测用户在腾讯地图中当前选中的地物（通过搜索结果列表点选或底图标记点击），自动提取地物名称、详细地址与精确坐标。
- **无缝回退视口中心**：未选中任何地物时，自动读取当前地图中心点经纬度。
- **GCJ-02 原生透传**：腾讯地图与高德地图底层坐标系均属 GCJ-02（火星坐标系），数据直接透传，无需任何非线性偏移计算或第三方接口转换，零精度损失。
- **新版 SSR 深度适配**：直接对接高德地图新版 SSR 逆地理编码路由（`/ssr/regeo`），支持精准落点插针、避让侧边栏以及自动展开周边与路线规划。
- **纯原生无依赖**：脚本采用 `@grant none`，体积仅约 6KB，无任何外部库依赖，与腾讯地图宿主完全解耦。

## 安装与使用

1. 在浏览器中安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）扩展。
2. 新建用户脚本，将 `tencent-to-amap.user.js` 的完整内容复制进去并保存。
3. 打开或刷新 [腾讯地图网页版](https://map.qq.com/)。
4. 页面右下角将出现浮动按钮：
   - 处于选定地物状态时：按钮显示深蓝色背景并展示地物名称，悬浮可查看完整地物信息与坐标；
   - 处于常规视口状态时：按钮显示天蓝色背景并展示当前中心经纬度；
   - 点击按钮即可在新标签页中打开高德地图对应位置。
